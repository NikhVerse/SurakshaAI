## 🏢 प्रणाली का परिचय (System Overview)

**SurakshaAI (सुरक्षा AI)** एक उद्यम-स्तरीय, एयर-गैप्ड और संप्रभु (sovereign) औद्योगिक सुरक्षा मंच है। इसे विशेष रूप से उच्च-जोखिम वाले क्षेत्रों जैसे तेल एवं प्राकृतिक गैस निष्कर्षण (Offshore & Onshore Oil & Gas), पेट्रोलियम रिफाइनरी, पेट्रोकेमिकल्स एवं भारी विनिर्माण संयंत्रों के लिए तैयार किया गया है।

यह प्रणाली **मशीन लर्निंग के माध्यम से संभावित गंभीर चोट अथवा मृत्यु (pSIF - Potential Serious Injury or Fatality)** का सटीक आकलन करती है, **IOGP 459/501 मानकों** के अनुरूप सुरक्षा बैरियर्स की निगरानी करती है, और स्थानीय ऑन-प्रिमाइसेस **लार्ज लैंग्वेज मॉडल (Ollama)** के जरिए सुरक्षा इंजीनियरों को स्पष्ट, व्याख्या-योग्य मार्गदर्शन प्रदान करती है।

## ⚠️ औद्योगिक चुनौतियाँ एवं आवश्यकता (The Industry Problem)

पारंपरिक सुरक्षा प्रणालियों में संयंत्रों के भीतर दर्ज होने वाली रिपोर्टों में कई गंभीर कमियां पाई जाती हैं:
1. **असंरचित डेटा की अधिकता (Dark Data):** संयंत्रों में दर्ज होने वाली 90% से अधिक नियर-मिस (Near-Miss) और खतरनाक स्थिति (Unsafe Act/Condition) रिपोर्टें असंरचित टेक्स्ट में होती हैं, जिन्हें पारंपरिक डेटाबेस प्रोसेस नहीं कर पाते।
2. **हेनरिक पिरामिड की भ्रांति:** पारंपरिक सोच यह मानती है कि सभी छोटी घटनाएं समान जोखिम रखती हैं। जबकि वास्तविकता में केवल 2% से 4% नियर-मिस घटनाओं में ही ऐसी उच्च-ऊर्जा (High-Energy Precursors) उपस्थित होती है जो जानलेवा हादसे का रूप ले सकती हैं।
3. **बैरियर क्षरण की उपेक्षा (Barrier Blindness):** प्रोसेस सुरक्षा के महत्वपूर्ण बैरियर (जैसे डबल ब्लॉक एंड ब्लीड, गैस डिटेक्टर्स, परमिट-टू-वर्क आइसोलेशन) बिना किसी प्रत्यक्ष विफलता के धीरे-धीरे कमजोर होते रहते हैं।
4. **डेटा संप्रभुता एवं गोपनीयता:** भारतीय विनियामक मानकों (OISD, DGMS, ISO 27001) के अनुसार रिफाइनरी या ऑफशोर प्लेटफॉर्म्स का संवेदनशील डेटा सार्वजनिक क्लाउड सर्वर्स पर नहीं भेजा जा सकता। सुरक्षा AI को पूर्णतः ऑन-प्रिमाइसेस व सुरक्षित बनाया गया है।

## ⚡ मुख्य कार्यात्मक स्तंभ (Core Functional Pillars)

### 1. कैलिब्रेटेड pSIF दुर्लभ-घटना जोखिम इंजन
- **गणितीय रूप से प्रमाणित कैलिब्रेशन:** असंतुलित डेटासेट में सामान्य AI मॉडल अधिक आत्मविश्वास (overconfidence) दिखाते हैं। सुरक्षा AI **Platt Sigmoid Scaling** का उपयोग करता है, जिससे मॉडल द्वारा दिया गया `0.75` का स्कोर वास्तव में 75% वास्तविक जोखिम को दर्शाता है।
- **सटीकता एवं संवेदनशीलता (PR-AUC 0.88):** उच्च-जोखिम वाले संकेतों को बिना किसी झूठे अलार्म (alarm fatigue) के सटीक रूप से चिन्हित करता है।
- **SHAP व्याख्यात्मकता:** प्रत्येक स्कोर के पीछे के स्पष्ट कारणों को प्रदर्शित करता है (उदा. ज्वलनशील हाइड्रोकार्बन रिसाव + आइसोलेशन में विलंब = उच्च pSIF जोखिम)।

### 2. क्रिटिकल बैरियर इंटेलिजेंस मैट्रिक्स (IOGP 459)
- 18 महत्वपूर्ण सुरक्षा बैरियर्स की वास्तविक स्थिति की निगरानी:
  - **इंजीनियरिंग बैरियर्स:** डबल ब्लॉक एवं ब्लीड (DBB), इमरजेंसी शटडाउन (ESD) वाल्व, एलईएल फ्लेम डिटेक्टर्स।
  - **प्रक्रियात्मक बैरियर्स:** परमिट-टू-वर्क (PTW) सत्यापन, लॉकआउट-टैगआउट (LOTO), ब्लाइंड फ्लैंज प्रबंधन।
  - **मानवीय कारक:** अत्यधिक कार्य-थकान नियंत्रण और दोहरे हस्ताक्षर प्रमाणीकरण।
- **बैरियर क्षरण सूचकांक (Degradation Index):** यह दर्शाता है कि संयंत्र के किस हिस्से में एक साथ कई रक्षात्मक परतें कमजोर पड़ रही हैं।

### 3. एयर-गैप्ड सोवरेन AI सेफ्टी कोपायलट
- **शून्य डेटा बहिर्गमन (Zero Cloud Egress):** संपूर्ण AI इन्फरेंस आपके अपने आंतरिक सर्वर पर Ollama के माध्यम से संचालित होता है।
- **व्यावहारिक एवं पेशेवर संवाद:** किसी प्रकार की अनावश्यक शब्दावली के बिना सीधे फील्ड इंजीनियरों और HSE प्रबंधकों को स्पष्ट, व्यावहारिक तकनीकी सुझाव देता है।

### 4. ऑपरेशनल डेटा इनजेशन हब
- **थोक CSV/Excel अपलोड:** पुरानी या बाहरी रिपोर्टों को सीधे डेटाबेस में मैप करके आयात करने की सुविधा।
- **लाइव रिपोर्ट प्रविष्टि:** फील्ड ऑपरेटरों के लिए त्वरित टेक्स्ट इनपुट, जिसमें टाइप करते ही स्वतः एंटिटी एक्सट्रैक्शन व जोखिम गणना दिखाई देती है।
- **SCADA सिमुलेशन:** दबाव, तापमान, कंपन और गैस डिटेक्टरों का लाइव टेलीमेट्री प्रवाह।

### 5. अनुपालन एवं अपरिवर्तनीय ऑडिट ट्रेल
- **पारदर्शी जवाबदेही:** हर समीक्षा, स्थिति परिवर्तन और निर्णय का अपरिवर्तनीय डिजिटल रिकॉर्ड, जिसमें ऑपरेटर का नाम, समय, IP पता और किए गए बदलाव सुरक्षित रहते हैं।
- **मानक अनुरूपता:** OISD-GDN-145, OSHA 1910.119 और ISO 27001 के पूर्णतः अनुकूल।

## 🇮🇳 भारतीय तेल एवं गैस संयंत्रों के प्रामाणिक अध्ययन (Indian Case Studies)

प्रणाली में भारत के प्रमुख ऊर्जा प्रतिष्ठानों से संबंधित 33 वास्तविक परिचालन केस स्टडीज पूर्व-संयोजित हैं:

| संयंत्र एवं स्थान | संपत्ति का प्रकार | पहचाना गया पूर्वगामी संकेत (Precursor) | प्रभावित सुरक्षा बैरियर |
|---|---|---|---|
| **मुंबई हाई नॉर्थ (Mumbai High)** | ऑफशोर उत्पादन प्लेटफॉर्म | गैस लिफ्ट मैनिफोल्ड फ्लैंज से हाइड्रोकार्बन सीपेज | पॉजिटिव फिजिकल आइसोलेशन (DBB) |
| **डिगबोई रिफाइनरी (असम)** | क्रूड डिस्टिलेशन यूनिट | हॉट वर्क परमिट के दौरान अवशिष्ट नेफ्था वाष्प | यांत्रिक वेंटिलेशन एवं PTW जांच |
| **हज़ीरा एलएनजी टर्मिनल (गुजरात)** | क्रायोजेनिक रीगैसीफिकेशन | BOG कंप्रेसर सील से सूक्ष्म रिसाव | इंस्ट्रूमेंटेड ESD ऑटोमेशन |
| **बाड़मेर तेल क्षेत्र (राजस्थान)** | मरुस्थलीय संकलन स्टेशन | भूमिगत पाइपलाइन कैथोडिक प्रोटेक्शन विफलता | संक्षारण निवारक सुरक्षा बैरियर |
| **पारादीप पेट्रोकेमिकल्स (ओडिशा)** | कैटालिटिक क्रैकिंग कॉम्प्लेक्स | पायरोलिसिस गैसोलीन पंप में असामान्य कंपन | रोटेटिंग उपकरण ट्रिप इंटरलॉक्स |

## 🚀 त्वरित स्थापना एवं आरंभ गाइड (Quickstart Guide)

### 1. रिपॉजिटरी क्लोन करें
```bash
git clone https://github.com/NikhVerse/SurakshaAI.git
cd SurakshaAI
```

### 2. बैकएंड सेवा कॉन्फ़िगरेशन (FastAPI)
```bash
# वर्चुअल वातावरण तैयार करें
python -m venv .venv
source .venv/bin/activate  # विंडोज उपयोगकर्ता: .venv\Scripts\activate

# आवश्यक लाइब्रेरी इंस्टॉल करें
pip install -r apps/api/requirements.txt

# डेटाबेस माइग्रेशन एवं वास्तविक डेटा फीड करें
python scripts/seed_data.py

# बैकएंड सर्वर प्रारंभ करें
uvicorn apps.api.app.main:app --host 0.0.0.0 --port 8000 --reload
```
*API अब `http://localhost:8000` पर सक्रिय है (दस्तावेज़ `/docs` पर उपलब्ध हैं)।*

### 3. फ्रंटएंड यूजर इंटरफेस (Next.js)
```bash
# नए टर्मिनल में
cd apps/web
npm install
npm run dev
```
*वेब पोर्टल अब `http://localhost:3000` पर उपलब्ध है।*

## ☁️ रेंडर क्लाउड परिनियोजन (Render Cloud Deployment)

SurakshaAI में पूर्व-कॉन्फ़िगर की गई [`render.yaml`](render.yaml) ब्लूप्रिंट शामिल है, जिसके माध्यम से आप **Next.js 16 वेब फ्रंटएंड** और **FastAPI बैकएंड** दोनों को [Render](https://render.com) पर एक साथ आसानी से परिनियोजित कर सकते हैं।

### विकल्प 1: 1-क्लिक ब्लूप्रिंट परिनियोजन (अनुशंसित)
1. अपने [Render Dashboard](https://dashboard.render.com/) में लॉगिन करें।
2. **New +** → **Blueprint** पर क्लिक करें।
3. अपनी GitHub रिपॉजिटरी चुनें: `https://github.com/NikhVerse/SurakshaAI.git`।
4. Render स्वतः [`render.yaml`](render.yaml) को पढ़कर दोनों सेवाओं को कॉन्फ़िगर करेगा:
   - **`suraksha-web`** (Next.js नोड वेब सेवा)
   - **`suraksha-api`** (FastAPI पायथन वेब सेवा)
5. **Apply** पर क्लिक करें। दोनों सेवाएं स्वचालित रूप से लाइव हो जाएंगी!

### विकल्प 2: केवल फ्रंटएंड वेब सेवा परिनियोजित करें
1. Render पर **New +** → **Web Service** पर क्लिक करें।
2. `https://github.com/NikhVerse/SurakshaAI.git` चुनें।
3. सेटिंग्स कॉन्फ़िगर करें:
   - **Runtime:** `Node`
   - **Root Directory:** `apps/web`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm run start`
4. **Create Web Service** पर क्लिक करें।

## 📡 API संदर्भ (API Reference)

- `GET /api/v1/dashboard/summary` — परिचालन मेट्रिक्स एवं बैरियर स्वास्थ्य सारांश
- `GET /api/v1/reports` — फिल्टर-सक्षम घटनाओं की रजिस्ट्री एवं pSIF रेटिंग
- `POST /api/v1/reports` — एकल रिपोर्ट का NLP विश्लेषण एवं जोखिम वर्गीकरण
- `POST /api/v1/reports/batch` — CSV/JSON बैच इनजेशन एंडपॉइंट
- `POST /api/v1/chat/stream` — सुरक्षा कोपायलट के साथ SSE स्ट्रीमिंग वार्तालाप
- `GET /api/v1/system/health` — इंफ्रास्ट्रक्चर डायग्नोस्टिक्स एवं डेटाबेस स्थिति
- `GET /api/v1/audit-log` — विनियामक ऑडिट के लिए अपरिवर्तनीय इतिहास
